# 链路: 音频到碎片

## 定位差异

主线能力是把可读的谱转成 `.gp`，信息已印在纸上，解码不是识别，误差下限为零。音频链路没有谱，产物不是转换结果，是碎片，即未来生成 `.gp` 所需的材料。

| 项 | PDF 链路 | 音频链路 |
| --- | --- | --- |
| 输入 | 制谱软件导出的 PDF | 音频加第三方和弦分析 |
| 信息完整性 | 完整，已印在纸上 | 不完整，必须补 |
| 误差下限 | 零 | 非零，依赖判断 |
| 产物 | `.gp` | 碎片，见下节 |
| 评价口径 | 音符与时值一致率 | 需人耳裁决的分歧点数量 |
| 共享层 | 形式层 `src/gp/write.py`，校验层 `src/gp/verify.py` | 同左 |

## 目标定义

核心：目标不是降低 dispute 数量，而是正确区分「算法能定的」与「必须人定的」。

| 方向 | 症状 | 性质 |
| --- | --- | --- |
| dispute 太少 | 脚本替人裁决，分歧被掩埋 | 违反「脚本不做解读」硬规则 |
| dispute 太多 | 噪声未清干净，浪费人的时间 | 工具没做完自己该做的 |

要降的是碎屑，时长小于 1.1 秒的切换抖动，不是真分歧。两者混在一张清单里是当前最该修的事。

## 三源与独立性

| 源 | 依据 | 录音 | 独立性 |
| --- | --- | --- | --- |
| chord-tell | 音频统计模型 | cover 版 | 独立 |
| 级数谱 | 人工转录 | 无 | 独立 |
| 自研 chroma | 纯 DSP，盲跑 240 模板 | 官方版 235 秒 | 独立 |

设计原则：

- 交叉验证的价值来自误差独立，不是来自源的数量
- 每个源必须盲跑，不得用其他源的结论当先验，否则独立性归零
- 脚本不裁决，只标出分歧，沿用 `doc/研究方向.md` 的硬规则
- 段落是独立单元，支持分批更新

## 已验证结论

| 结论 | 依据 |
| --- | --- |
| 调为 D 大调 | 三源独立同意，chord-tell 14/15 diatonic，级数谱词汇表整体落在 D 调，自研 chroma 按时长 73% |
| 前奏进行为 4 5 6m 循环两次 | 两个独立录音两套独立算法给出同一进行 |
| 两录音时间偏移恒定约 2.5 秒 | 前奏两次 G A Bm 的偏移分别为 2.49 与 2.63 秒，官方版前面多约 2.5 秒引子 |
| chord-tell 的 Abdim 为误判 | 三源无一支持，自研读数在对应位置为 D，级数谱通篇无 dim |

## 已知缺陷

| 缺陷 | 说明 |
| --- | --- |
| 无和弦状态缺失 | 匹配器有 240 个模板但无「无和弦」状态，任何输入都被塞进某个和弦，前奏铺垫段被误配 |
| 大小三度残留混淆 | clash 14.2%，Dm 与 Am 有零星残留 |
| 低音区分辨率不足 | bass chroma 的 in-scale 偏低，调外音能量偏高 |
| sus 无独立证据 | sus 占 19%，吉他上常见，但无独立证据证明为真，需人耳 |
| 三度音可靠性 | 根本瓶颈是三度音是否可靠，不是模板数量 |

## 踩过的坑

| 坑 | 现象 | 修正 |
| --- | --- | --- |
| 截图估读时间戳推 BPM | 误差正负 0.3 秒，一拍 0.5 到 0.8 秒，噪声大于信号。与 200 组随机 onset 对比 gain 全在正负 0.035 内 | 换真实音频时间戳 |
| 幅度谱开方压缩 | F#/F 判别比从 1.89 掉到 0.97，大小三度完全不可分，D 全塌成 Dm | 保持线性幅度 |
| 一次改两个变量 | 同时加低音加权与动态压缩，无法定位元凶 | 单变量，先诊断再改 |
| 纯网格搜索找 BPM | 格子越密残差自动越小，240 BPM 会拿第一名 | 必须设随机基线对比 |
| 以 dispute 数量当优化目标 | 分歧数升降不代表质量升降 | 目标改为正确区分算法能定与人必须定的 |

实验细节与参数见 `Generate/Attempt-02/记录.md`。
