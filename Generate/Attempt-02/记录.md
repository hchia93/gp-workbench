# Attempt-02 转换记录

曲目: 與其愛你 - Vast & Hazy
来源: 无 PDF, 源为音频与第三方和弦分析平台
目的: 建立不依赖 PDF 的第三条输入路径, 记录有效/无效方法

## 1. 目标定义

核心: 目标不是降低 dispute 数量, 而是正确区分「算法能定的」与「必须人定的」。

| 方向 | 症状 | 性质 |
| --- | --- | --- |
| dispute 太少 | 脚本替人裁决, 分歧被掩埋 | 违反「脚本不做解读」硬规则 |
| dispute 太多 | 噪声未清干净, 浪费人的时间 | 工具没做完自己该做的 |

要降的是碎屑, 时长小于 1.1 秒的切换抖动, 不是真分歧。两者混在一张清单里是当前最该修的事。

## 3. 输入契约

管线不关心音轨怎么来的。

| 项 | 内容 |
| --- | --- |
| 契约 | [任意来源] -> 本地文件 -> 单声道 wav -> 分析层 |
| 核心管线 | 只吃 wav, scipy.io.wavfile 直接读, 零外部依赖 |
| 压缩格式 | 需要 ffmpeg, 降级为可选前置工具 |
| 长度 | 不需要整首歌, 前奏加一段主歌即可, 流行歌和弦本来就是循环 |

## 4. 源清单

| 源 | 类型 | 覆盖 | 可信度 |
| --- | --- | --- | --- |
| chord-tell 时间轴 | 音频统计模型 | 0:00-0:32 前奏 | 平台称 80% |
| 级数谱 | 人工转录 | 主歌A 15 行 | 高, 但无时间信息 |
| 和声约束 | 纯符号先验 | 全曲 | 不看音频, 与前两者正交 |

关键设计原则: 交叉验证的价值来自误差独立, 不是来自源的数量。再接三个同源的自动识别服务, 验证值等于零。

## 5. 有效方法: 符号层交叉验证

不碰音频, 纯符号推理。实现在 src/chord/roman.py 与 src/chord/crosscheck.py。

| 检验 | 做法 | 产出 |
| --- | --- | --- |
| 调性推断 | 12 个大调各数自然音级和弦数 | D 调 14/15, 次名 A 调 10/15, 差距大不并列 |
| 词汇表检验 | 时间轴和弦转级数, 与级数谱词汇表比对 | 隔离出调外和弦 |
| 段落匹配 | 最长公共连续子串 | 判定时间轴属于哪一段 |
| 候选生成 | 对调外和弦按共享音数列调内候选 | 只列不裁决 |

## 6. 符号层结论

| 项 | 结论 |
| --- | --- |
| 调性 | D 大调, 两个源独立同意 |
| 依据 | 级数谱词汇 1 2m 3m 4 5 6m 在 D 调下展开为 D Em F#m G A Bm, 与时间轴和弦集合完全重合 |
| 时间轴级数序列 | 4 5 6m \| 4 5 4/5 6m \| #4dim 1 5 4/5 3m 4 \| 5 1 |
| 误差落点 | 15 个和弦仅 1 个调外, Abdim = #4dim, 级数谱通篇无 dim |
| Abdim 候选 | G 或 Bm 各共享 2 个音, 上下文 Bm -> ? -> D, 脚本不裁决 |
| G/A | 两次均紧跟 A 之后, 是 5 级挂留润饰, 级数谱粒度较粗省略, 归类为粒度差异不计入错误 |
| 段落归属 | 与主歌A 最长仅 3/15 连续吻合, 判定为前奏 |
| 元结论 | 15 个和弦符号层自动消化 14 个, 需人耳裁决 1 个, 全程未碰音频 |
| 依赖 | 该层只用标准库, numpy 与 scipy 均未用上 |

## 7. 和弦词汇表扩展

## 8. 非对称匹配

原理: chroma 无法区分和弦音与叠在上面的旋律音, 对称余弦相似度会因为多一个旋律音就把正确和弦推走。改成缺和弦音重罚, 多余音轻罚。

用 mean 而非 sum 聚合, 否则五音和弦靠覆盖更多音级取胜。

实现: src/chord/audio.py 的 match_asymmetric。

## 9. 三轮尝试的轨迹

| 轮次 | 做法 | 结果 | 结论 |
| --- | --- | --- | --- |
| 一 | 非对称匹配单独上 | sus 和弦占 72%, 三和弦份额从 100% 掉到 24% | sus 模板跳过三度那一格, 而三度是最容易被旋律和泛音污染的音级, 低约束模板会挤掉高约束模板 |
| 二 | 加和弦品质先验 QUALITY_PRIOR | sus 压到 5-17%, 但大小三度混淆原样返回, clash 回到 19-21% | sus 与 clash 此消彼长, 压掉一个另一个就回来 |
| 三 | 移动平均换成移动中位数 smooth_median | diatonic 67.2 到 73.0, clash 21.7 到 14.2, 两轴均优于基线 | 旋律音是短暂尖峰, 和弦音持续, 中位数滤前者留后者, 尖峰恰好最常落在决定大小调的三度上 |

贯穿三轮的结论: 瓶颈始终是三度音的可靠性, 不是模板数量。

## 10. 符号层改动

| 改动 | 说明 |
| --- | --- |
| is_diatonic 改为基于完整音集 | 以前按三和弦品质判, A7 会被当成 A 放过。现在 D7 在 D 调正确判为非调内 |
| 新增 triad_degree | 只看底层三和弦的级数, A7 与 A 都读作 5。级数谱是三和弦写法, 扩展音不能被当成不同和弦, 否则产生假分歧 |
| 新增 QUALITY_PRIOR | 和弦品质出现频率先验, 防止无三度模板通吃 |
| 新增 smooth_median | 中位数聚合 |

## 11. variant 系统

粒度是乐句不是单个和弦。

| 理由 | 说明 |
| --- | --- |
| 组合爆炸 | 每个分歧点约 3 个候选, 27 个分歧点做笛卡尔积是 3 的 27 次方, 乐句分组让组合数从指数变线性 |
| 听感 | 听的时候本来就要听上下文 |
| 语义 | 编曲意图是句子级的 |

分组判据: 相邻分歧点间隔小于 3 秒归为一组, GAP 常数在 src/chord/variants.py。

每组三种策略, 去重后保留:

| 策略 | 内容 |
| --- | --- |
| A | 检测原样 |
| B | 拉到最近调内 |
| C | 前一个和弦延续 |

B 策略的回退: 共享音匹配失败时按根音半音距离找最近调内三和弦, 否则标签会与内容不符。

实现: src/chord/variants.py。

## 12. 已放弃: 段落自动切分

吉他谱的重复段落本来就带变化, 自动 shrink 出来的结果仍需人重新拆, 不如 manual。此路不再尝试。

## 13. 无效方法: 截图估读时间戳推 BPM

| 项 | 内容 |
| --- | --- |
| 数据来源 | 时间戳从截图像素量得, 误差 +/-0.3 秒 |
| 信噪比 | 一拍 0.5 到 0.8 秒, 噪声大于信号 |
| 纯网格搜索的陷阱 | 格子越密残差自动越小, 不设基线时 240 BPM 拿第一名, 是过拟合 |
| 基线对比法 | 真实 onset 与 200 组随机 onset 在同一网格上比残差 |
| 结果 | gain 全部落在 +/-0.035 秒内, 与随机无本质区别 |

| BPM | gain |
| --- | --- |
| 70 | +0.035 |
| 80 | +0.015 |
| 88 | -0.011 |
| 110 | +0.026 |
| 120 | -0.012 |

结论: 该组时间戳无可提取的节拍信息。截图这条路对时值分析无效, 必须换真实数据。

## 19. 踩过的坑

| 坑 | 现象 | 修正 |
| --- | --- | --- |
| 截图估读时间戳推 BPM | 误差正负 0.3 秒, 一拍 0.5 到 0.8 秒, 噪声大于信号 | 换真实音频时间戳 |
| 幅度谱开方压缩 | F#/F 判别比从 1.89 掉到 0.97, 大小三度完全不可分, D 全塌成 Dm | 保持线性幅度, compress 1.0 |
| 一次改两个变量 | 同时加低音加权与动态压缩, 无法定位元凶 | 单变量, 先诊断再改 |
| 非对称匹配未加品质先验 | sus 模板无三度, 系统性比三和弦易满足, 占 72% | 加 QUALITY_PRIOR |
| sus2 与 sus4 互为转位 | Dsus2 与 Asus4 音集完全相同, chroma 不可区分 | 只能靠 bass 根音分 |
| 以 dispute 数量当优化目标 | 一轮改动使 dispute 从 19 升到 27, 但其中含以前被错误消化的真分歧 | 目标改为正确区分算法能定与人必须定的 |
