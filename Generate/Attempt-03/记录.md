# Attempt-03 转换记录

曲目: H'aanit, the Hunter - Octopath Traveler (arr. John Oeth)
来源: Finale 排版, 经 PDF-XChange 4.0 打印的 PDF, 2 页 35 小节, 五线谱 + TAB, Drop D, Capo 3, 6/8
目的: 记录有效/无效方法, 后期编译成模板 how-to

## 1. PDF 形态识别

| 判定 | 方法 |
| --- | --- |
| Finale 排版 | 字体 Maestro, 一份 TrueType 无 ToUnicode, 一份 Type0 Identity-H |
| PDF-XChange 打印 | Producer = PDF-XChange 4.0, 字符以 `(x) Tj` 字面量写入 |
| 路线 | survey 判 `image`, 实为 text-layer: extract_content 只收 Qt 的 `<hex>`, 字面量整段丢弃 |

## 2. 字面量适配

`literal_patch.py` import 即替换 `extract_content.run` 与 `page_fonts`, 不改 src。

| 项 | 有效做法 |
| --- | --- |
| tokenizer | 字面量分支放在最前, 处理 `\n` 类转义与八进制 |
| 单字节字体 | 无 ToUnicode 时按 cp1252 取字符, Type0 按两字节取码 |
| 重叠字形 | 两个声部共用一个音时 Finale 在同一坐标画两次, 读成 `33`, 按字符加坐标去重 |
| 结果 | route 改判 text-layer, 271 个品位全部读出, 无识别误差 |

Attempt-01 的 Quartz 适配是同一个缺口, 两次都没进 `extract_content.py`。

## 3. 节奏

| 方法 | 判定 | 依据 |
| --- | --- | --- |
| read_rhythm_tab | 无效 | 本谱 TAB 无符干, 节奏只在五线谱 |
| read_rhythm_notation | 无效 | 只认 Bravura 码位, Maestro 不同 |
| TAB 列对照渲染图 | 有效 | TAB 列即起音点, `render.py` 出 PNG 逐小节读五线谱, 写进 `build.py` 的 PLAN, 每小节一行 |
| 连音弧 | 有效 | 高倍裁图看弧线, 同品为延音, 异品为击勾弦 |

| 规则 | 内容 |
| --- | --- |
| 6/8 | 6 列即全八分, 列少处是持续音 |
| 单声部 | 每列时值到下一列为止, 延音靠模板自带的 LetRingThroughout |
| 校验 | verify 35/35 闭合 |

## 4. capo 与音高

| 项 | 事实 | 依据 |
| --- | --- | --- |
| GP 存音高 | Midi 与 ConcertPitch 含 capo, 默认移调下 TransposedPitch = ConcertPitch + 12 | 曲库带 capo 的 GP 存档全部如此 |
| 坑 | 调号照 PDF (capo 相对) 写, 音高按发声写, 满谱升降号 | 第一版 F 调号配 Fm 发声 |
| 五线谱对上 PDF | 轨道 `<Transpose>` Chromatic = capo, Octave = -1, TransposedPitch 写 capo 相对音 + 12 | 用户 GP 验证 |
| 调号 | MasterBar Key 存发声调, 本曲 -4 (Ab) / -1 (F), GP 按轨道移调显示成 F / D | 同上 |
| 拼写 | written 按段落调性拼, concert 由 written 字母 +2, 半音 +3 推出 | Hooktheory 标 F 小调 / F 大调, 与换算一致 |

## 5. 和弦图

| 项 | 事实 |
| --- | --- |
| 命名 | 带 capo 时 GP 按手型存名与 KeyNote, capo 1 存档里 x32010 存为 C |
| chord_diagram.py | 6 弦写死 E, Drop D 推断错, 按拍内音推断会把旋律装饰音算进和弦, 本曲手工分析 |
| 标记密度 | 指弹按小节读手型, 每小节重标, 没有手型的小节空着 |
| baseFret | Fret 写绝对品, 最高品 > 5 时 baseFret = 最低按品 - 1 |
| beat 内顺序 | `ConcertPitchStemOrientation`, `Chord`, `Notes` |
| DiagramWorkingSet | 曲库所有带标记的存档都填满, 本次照填 |

## 6. GP8 样式表

| 项 | 事实 |
| --- | --- |
| 开关所在 | GP8 存档的 `Stylesheets/score.gpss` (protobuf) 另存一份和弦开关, 与 BinaryStylesheet 并存 |
| 字段 | `6/9` 和弦名 (`/3` = chordNameStyle + 1), `6/10` 页首和弦表, `6/11` 谱内和弦图, 后两组 `/1` 开关, `/2/1` 尺寸 (厘米) |
| 开关值 | 1 显示, 2 隐藏。`6/11` 由曲库 8 个 GP8 存档对照得出, `6/10` 按同构推断, 用户 GP 验证 |
| 修改 | 单字节原地改, 不重编码。`scoreview*.gpss` 的 6/9-11 为空, 不覆盖总表 |
| 验证过程 | 只改 BinaryStylesheet 且清空 WorkingSet 时谱内不显示, 改 `.gpss` 且填回 WorkingSet 后显示, 两项未分开验证 |
| style.py | 只替换 BinaryStylesheet 三件套, 不碰 `.gpss`, 与其 docstring 所说「GP8 认自己编译的 BinaryStylesheet」可能冲突, 待查 |

## 7. 速度

PDF 无速度标记。♩=120 与 ♩=90 均被否, 用户定 ♩=74。Hooktheory 标 81 BPM (3/4), 未采用。

## 8. 缺口

| 缺口 | 说明 |
| --- | --- |
| extract_content.py | 不收字面量字符串, 补丁在 `literal_patch.py` |
| read_rhythm_notation | 不认 Maestro, 需码位映射 |
| gp_ops/writer.py | TUNING 写死标准调弦, 无调号, 泛音, 滑音, FreeText, 和弦, 本次在 `build.py` 里 monkeypatch |
| chord_diagram.py | 6 弦写死 E |
| style.py | 不处理 `.gpss` |
| 两声部 | 旋律与低音未拆声部 |
| 延长记号 | Fermata 写法无样本, GP 内未单独确认 |

## 9. 文件

| 文件 | 用途 |
| --- | --- |
| `literal_patch.py` | extractor 字面量补丁 |
| `gpw.py` | 带补丁的 CLI, 参数同 `gp-workbench.py` |
| `columns.py` | 每小节 TAB 列与相对位置, 定节奏用 |
| `render.py` | PDF 渲染 PNG, 需 pypdfium2 |
| `build.py` | 全流程: 品位, PLAN, 技巧, 调号, 和弦, 样式开关 |

在仓库根目录运行:

```bash
python Generate/Attempt-03/gpw.py route <file.pdf>
python Generate/Attempt-03/build.py <file.pdf> <template.gp> <out.gp>
```

template: 任一 GP8 存过, 单轨, 无和弦图的 .gp。
